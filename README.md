Harmattan Mail is an original 3D bush-pilot flight game over a West African Sahel landscape in the dry season: laterite strips, baobabs, mud-brick villages and a painted market-town minaret, flown in a high-wing plane with Ankara livery.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Keyboard and mouse to fly.
